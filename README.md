# 🎮 Secret World - Adivinhe as palavras!

Um jogo simples e divertido de adivinhação de palavras, feito com **React**.

## 📌 Sobre o Projeto

O Secret World é um jogo onde o jogador deve adivinhar uma palavra com base em uma dica fornecida. A cada rodada, o usuário tem um número limitado de tentativas para descobrir a palavra secreta, digitando uma letra por vez.

## 🛠 Tecnologias Utilizadas

- [React](https://reactjs.org/)
- HTML5
- CSS3
- JavaScript (ES6+)
- React Scripts (CRA)

## 🚀 Como Rodar o Projeto

Clone o repositório:

git clone https://github.com/Gabr1elle/Secret-World.git
cd Secret-World

Instale as dependências: 

npm install

Rode o projeto com: 

npm start
